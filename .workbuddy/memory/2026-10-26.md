## 环境问题：Android Studio Rabbit 1 (2026.2.1) 查找跳转/删除键失效

**现象**：⌘F 搜索后点 ▲/▼ 或按 Enter 不跳到匹配行；选中代码按 Delete 删不掉。同一台 Mac 上 Panda 3 (2025.3.3) 一切正常。

**根因（已从 idea.log 确认）**：
- 插件 `Tencent Cloud CodeBuddy 4.12.40032586`（id `com.tencent.cloud.codingcopilot`，目录 `~/Library/Application Support/Google/AndroidStudio2026.2.1/plugins/coding-copilot-jetbrains`）在 `SelectionModel` 选区变更回调里抛
  `java.lang.NoClassDefFoundError: com/intellij/ui/jcef/JBCefBrowserBase`
- 该类在 platform 262（Rabbit 1 = AI-262.9437.185）已不存在，插件只声明 `since-build="222"` 无 `until-build`
- 调用链：`SearchResults.moveCursorTo` → `SelectionManager.updateSelection` → `SelectionModel.setSelection` → `CodeBuddy InlineChatGutterIcon.selectionChanged` 抛异常 → 导航/滚动与删除命令提前中断
- 佐证：idea.log 中 "Plugin to blame: Tencent Cloud CodeBuddy" 出现 230 次；日志目录另有多个 `uiFreeze-*` 转储

**结论**：不是 keymap / IdeaVim / 输入法 / 硬件问题。Panda 3 未装该插件（装的是 `qoder-cn-jetbrains`），所以正常。

**处置**：在 Rabbit 1 中禁用或升级 CodeBuddy 插件后重启即可。

## 网络层取消保证改造（core:network / app）
需求：Activity/Fragment/ViewModel 销毁时，网络请求与协程必须一起结束，不能残留。
- 经核查，`OkHttpAwait.await()` 早已用 `suspendCancellableCoroutine + invokeOnCancellation { cancel() }`，get/post/put/delete 主链路取消时**会真正断开 OkHttp socket**，本身没问题。
- 但 `download` 字节拷贝循环、`ProgressRequestBody.writeTo` 文件写入循环是阻塞式、未检查取消，大文件会"慢半拍"。
- 改造：
  - `ProgressRequestBody` 增加 `isActive: () -> Boolean` 参数，写文件前检查，取消即抛 `CancellationException` 即时中断上传。
  - `SimpleHttp.upload` 把 `coroutineContext[Job]?.isActive` 传进 ProgressRequestBody。
  - `SimpleHttp.download` 循环内加 `(coroutineContext[Job])?.ensureActive()`，取消即停。
  - 在 `OkHttpAwait`/`SimpleHttp`/`ExampleHttpRequest` 头部补"取消保证"文档（lifecycleScope=界面销毁即停；viewModelScope=扛旋转）。
- 注意：仍无法本地编译（沙箱无 Android SDK），需用户 `./gradlew :core:network:compileDebugKotlin` 验收；确认 `ensureActive` 已导入（kotlinx.coroutines.ensureActive 扩展）。
