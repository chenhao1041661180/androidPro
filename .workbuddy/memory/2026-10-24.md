## 编译报错修复（同日晚）

- `BaseDao.kt`：`import androidx.room.SimpleSQLiteQuery` 改为 `import androidx.sqlite.db.SimpleSQLiteQuery`（`SimpleSQLiteQuery` 属于 `androidx.sqlite.db`，不是 `androidx.room`）。
- 新增 `core/list/RemoteKey` 接口（`val nextPage: Int?`）作为 `Key` 泛型上界；`BaseRemoteKeyDao`/`ListCache`/`BaseListCache`/`ListRepository`/`BaseListViewModel`/`BaseListFragment`/`ListRemoteMediator` 的 `Key` 加 `: RemoteKey`；`PostRemoteKey` 实现 `RemoteKey`。
  原因：`BaseListCache.nextPage()` 访问 `Key.nextPage`，原 `Key` 无约束导致 unresolved；沿泛型链同步加约束，避免"类型参数不满足上界"。

## 框架泛型约束约定（避坑）
- `Key` 必须有 `: RemoteKey` 上界：`BaseListCache.nextPage()` 需访问 `Key.nextPage`。
- `Entity` **必须**加 `: Any` 上界：`PagingSource<Key : Any, Value : Any>` 与 `RemoteMediator<Key : Any, Value : Any>` 的 `Value` 自带 `: Any` 上界，无约束的 `Entity`（默认 `Any?`）传进去不满足，IDE 会提示 "Add 'Any' as upper bound for Entity"。
  已在 `ListCache`/`BaseListCache`/`ListRepository`/`BaseListViewModel`/`BaseListFragment`/`ListRemoteMediator` 统一加 `Entity : Any`；`ListApi<Entity>`、`BaseDao<T>` 无需（`List<Entity>` 不要求 `: Any`，具体实体 `PostEntity` 天然非空）。
  （更正：早前误判为"Entity 不需要约束"，实际是被 `PagingSource`/`RemoteMediator` 的 `Value : Any` 上界卡住。）
